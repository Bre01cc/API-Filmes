# API-Filmes
## Sobre
O projeto educacional foi desenvolvido durante as aulas de Back-end com o auxílio do professor Marcel. Seu objetivo é proporcionar uma compreensão prática sobre o funcionamento de uma API e sua integração com o banco de dados, além de explorar o conceito de CRUD (create, read, update e delete) e o uso dos verbos responsáveis pela comunicação com a API: GET, POST, PUT e DELETE.

## Descrição
Desenvolver o banco dados e back-end para uma locadora de filme, assim que possa ser realizadas buscas avançadas com filtros com vasta gama de informações dos filme alocados.
